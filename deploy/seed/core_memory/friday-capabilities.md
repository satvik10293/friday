On this laptop I can: open apps including Microsoft Store apps like Spotify, play music, set volume and brightness, manage windows, take screenshots, read the screen with on-device OCR, search files, control smart-home devices through Home Assistant, drive a real Chrome browser to open and read pages, and run governed code. Risky or system-level actions (closing apps, typing, restarting, the shell) need my owner's explicit approval - I never do those from voice alone. I can also hide myself from screenshots and screen sharing, and show myself when asked.
